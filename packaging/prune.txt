# What build_runtime.sh deletes from the runtime folder after installing, before precompiling.
# One rule per line: <kind> <pattern>
#   path <glob>   a path relative to the runtime folder (find -path; * also matches /)
#   dir  <name>   every directory with this name under site/ (find -name)
#   file <glob>   every file with this name anywhere (find -name)
# Keep it conservative: only things nothing imports at run time. `testing` packages stay
# (numpy.testing, torch.testing are imported by the libraries themselves); only `tests` go.
# The relocated end-to-end run (rehearsal file through engine + translator) is the check.
