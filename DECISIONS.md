## Live pipeline
- 2026-10-21 — Two processes: the **engine** (audio → Silero VAD v5 ONNX → pause/force commits → STT) runs in the STT model's venv and emits JSON lines; the **orchestrator** (language tracking, translation, ProPresenter, logs, web page) runs in `.venv-mt`. Separate processes avoid NeMo vs MLX-LM dependency conflicts. The engine sends events on a private dup of stdout and points fd 1 at stderr, because NeMo prints to stdout.
- 2026-10-21 — NeMo `transcribe()` costs ~0.5–0.9 s per clause on CPU. The engine calls preprocessor+encoder on **MPS** and decodes on **CPU**: outputs identical to CPU `transcribe()` on 6/6 test segments, ~15× faster (~0.07–0.12 s per clause). Full-MPS (decoder on MPS too) truncated output, so it is not used.
- 2026-10-21 — Clause policy: commit at a ≥350 ms pause; force a cut after 7 s of continuous speech at the least-voiced frame in the last 2.5 s; fragments under 4 words (unless ending in ?/!) are held ≤1.2 s — Jackrabbit puts a period after short fragments like "Dar acum.", so punctuation alone is not a reliable signal — and merged with the next clause before translation.
- 2026-10-21 — Language auto-detect: Parakeet-TDT-0.6B-v3 (RO+EN) transcribes each clause alongside the Romanian model; a stopword/diacritic score with 2-clause hysteresis picks the language. English clauses use Parakeet's text. Manual lock (RO→EN / EN→RO) skips the extra model.

## Whistle (English STT for EN→RO) — 2026-10-22
- Package `cactus-needle` 3.2.8 (engine 3.3.3), Apache-2.0. Python API confirmed in `needle/agent/whistle.py`: `needle.Whistle(weights=None, buffer_size=262144)` with `.transcribe(audio, language, keywords, word_timestamps)` and `.stream(chunks, language, keywords)`. `stream()` is a generator over an iterable of ~1 s 16 kHz float chunks: it yields `{"text","words"}` = **committed** text (words with start/end from stream start), `"pending"` = provisional tail, `"pass_ms"`, and a final tail dict when the iterable ends. It wraps C `needle_stream_transcribe_process` / `needle_stream_transcribe_stop`. One model per process; not thread-safe (all calls run behind a lock).
- **Depth:** the Python API and the engine library expose no depth/`--audio-depth` control (no symbol, no string). Depth is fixed when a `.cact` is built (`needle whistle build --layers 2..8`, needs the `[train]` extra and the base checkpoint). The setting is therefore `whistle.depth` → weights file in config.yaml; `full` = the shipped `whistle.cact` (default).
- **Offline:** telemetry (`needle/_telemetry.py`, HTTPS POST to a Supabase endpoint on a daemon thread) is disabled by `NEEDLE_TELEMETRY=0` and `DO_NOT_TRACK=1`, set before import. The engine dylib and weights are vendored in `models/whistle/` and pinned with `NEEDLE3_LIB_PATH` / `NEEDLE_WHISTLE_WEIGHTS`, plus `HF_HUB_OFFLINE=1`, so first-use downloads can't happen.
- **Scope:** Whistle replaces Parakeet only for English text. In EN→RO (locked) mode it streams; committed words are cut into clauses by punctuation, word-timestamp gaps and a max chunk length. In Auto mode, language detection still uses Parakeet + Jackrabbit (Whistle has no Romanian); when a clause is English, Whistle re-transcribes that clause with language "en" and the keywords. RO→EN is unchanged.
